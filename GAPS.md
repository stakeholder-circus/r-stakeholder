# R Gaps

- `r-stakeholder.later-family-dedicated-ports-deferred`: healthcare, EV charging, protocol, quantum, blockchain, and extended AI operations beyond modern-core are grouped fallback events in Tranche C.
- `r-stakeholder.live-provider-runtime-deferred`: `--experimental-provider` fails fast because deterministic CI must remain provider-free.
- `r-stakeholder.ansi-parity-normalized`: R text output avoids ANSI decoration; JSON parity is authoritative.
- `r-stakeholder.duration-zero-normalized`: deterministic R runs emit one stable cycle for `--duration 0` instead of blocking forever during validation.
- `r-stakeholder.codeql-r-lane-unavailable`: CodeQL workflow is a note because R is not a supported first-class CodeQL language lane here.
